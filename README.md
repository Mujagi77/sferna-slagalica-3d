# 🌐 Sferna Slagalica Brojeva 3D

Moderna 3D slagalica smeštena na rotirajuću sferu, napravljena u jednom HTML fajlu (`index.html`) pomoću Three.js grafike.

## ✨ Ključne Funkcije

- **Interaktivna 3D sfera:** Slobodna rotacija, dinamičko osvetljenje i prilagodljiva kamera.
- **Pametni rešivač i saveti:** Ugrađeni *A\*** algoritam automatski pronalazi najkraće rešenje ili nudi nagoveštaje.
- **Progresivni nivoi i teme:** Od 3×3 do 6×6 tabli, uz različite vizuelne teme (Neon, Smaragd, Zlato...) i zvukove preko Web Audio API-ja.
- **Lokalno pamćenje:** Čuva otključane nivoe i najbolje rezultate (rekorde) u pretraživaču.

## 🚀 Brzi Početak

Samo preuzmi i otvori `index.html` u bilo kom modernom web pretraživaču. Nema instalacije ni dodatnih fajlova.

## 🎮 Kontrole i Prečice

- **Miš / Prst:** Prevlačenjem okrećeš sferu, a klikom na pločicu pored praznog polja je pomeraš.
- `U` ili `Z` – Vrati potez (Undo)
- `H` – Prikazuje savet (Hint)
- `R` – Ponovo izmešaj tablu
- `M` – Otvara meni za izbor nivoa
